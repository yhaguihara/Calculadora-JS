# 🧮 Calculadora com JavaScript

Uma calculadora web simples desenvolvida para praticar a integração entre HTML, CSS e JavaScript em uma interface interativa.

## 📖 Sobre o projeto

A **Calculadora com JavaScript** apresenta botões para operações matemáticas básicas e utiliza código JavaScript para controlar a interação e calcular os resultados.

## ✨ Funcionalidades

- ➕ Adição.
- ➖ Subtração.
- ✖️ Multiplicação.
- ➗ Divisão.
- 🖱️ Interface com botões para entrada de valores e operações.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da calculadora.
- **CSS3:** apresentação visual.
- **JavaScript:** lógica das operações e interação com os botões.

## 📂 Estrutura do projeto

```text
Calculadora-JS/
├── index.html

└── README.md
```

## 🚀 Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/Calculadora-JS.git
   ```
2. Entre na pasta:
   ```bash
   cd Calculadora-JS
   ```
3. Abra `index.html` no navegador.

Não é necessário instalar dependências para executar a versão estática.

## 🎯 Objetivo de aprendizagem

Praticar manipulação de eventos, lógica de programação e integração de HTML, CSS e JavaScript na criação de uma ferramenta interativa.
